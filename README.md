# BlaBlatopia School

Демонстрационный сайт вымышленной онлайн-школы английского языка BlaBlatopia. Школа, цены, отзывы и показатели придуманы; форма заявки ничего не отправляет.

Сайт — один файл `index.html`: картинки и видео встроены в него, поэтому он работает на любом статическом хостинге, в том числе GitHub Pages.
